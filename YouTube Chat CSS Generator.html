CSS cho OBS

Cách dùng

  1. Mở YouTube Studio, vào Phát trực tiếp, bấm Popout chat và sao chép URL (dạng youtube.com/live_chat?is_popout=1&v=…).
  2. Trong OBS: Add, Browser Source, dán URL, đặt Width 400 và Height 600.
  3. Xóa CSS mặc định trong ô Custom CSS, dán CSS ở trên rồi bấm OK.
